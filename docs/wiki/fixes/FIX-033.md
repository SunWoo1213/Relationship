# FIX-033 · 위임·검증 절차 보강 — 변이에 강한 테스트 · 계획에 없는 값은 먼저 보고 · 증거는 전체 출력

발견: 2026-10-11 · P8-frontend U0~U2 진행 중 사용자 요청 "약점 해결 프로세스 시작" | Refs: FIX-033 L-002 L-004 원칙8 R-U1-1 R-U1-3 R-31-3 R-14-7

## 증상

1. **구현자 테스트가 계약을 고정하지 못했다(R-U1-1)** — U1 테스트 7건은 `last_contact_at = max(events.occurred_at)` 를 단언하지 않았다. `func.max → func.min` 변이에도 7건 전부 통과(`docs/wiki/packages/P8-frontend/evidence/20261011-verifier-u1-mutation.txt`). verifier 의 변이 시험이 없었다면 커밋됐다.
2. **계획에 없는 값을 구현자가 혼자 정했다(R-U1-3)** — `UPCOMING_SCHEDULES_LIMIT = 10` 은 01-plan 에 없었고 테스트도 없었으며 주석 근거("24시간 이내")가 틀렸다. 사용자 결정으로 사후 정리. U2 의 `Event.person_id` 추가 방어선처럼 계획 밖 판단이 보고에만 나오고 사전 확인이 없다.
3. **구현자 증거가 요약본(R-31-3)** — FIX-031 구현 증거 `docs/wiki/fixes/evidence/20261011-fix031-test-guards.txt` 는 섹션 요약. verifier 가 전체 원문을 따로 남겼다. `verification.md` 의 "가시적 증거" 취지에 못 미친다.
4. **메인 세션 독립 확인이 막힌 적(U0)** — 변이 시험 명령에 `rm -rf "$R"`(변수 경로)가 들어가 권한 거부, 첫 시도는 commit-guard 가 임시 저장소의 `git commit` 까지 막음. 우회하지 않고 verifier 에 넘겼지만, 다음에 같은 시행착오를 반복하지 않을 방법이 문서에 없다.

## 원인

구현 에이전트 정의·위임 프롬프트에 "테스트 통과" 만 있고 "그 테스트가 무엇을 잡는가" 를 요구하지 않았다. 계획이 상한·정렬·2차 키 같은 세부를 다 정하지 않으면 빈칸을 구현자가 채우는데, 채우기 전에 멈추라는 규칙이 없다. 증거 규칙이 "파일로 남긴다" 까지만 있고 "전체 출력" 을 요구하지 않는다.

## 수정안 (파일 · 방식 · 회귀 테스트) — 문서만

1. `.claude/agents/backend-agent.md`·`eval-agent.md`·`frontend-agent.md` 하네스 규칙(공통 절)에 네 줄((a)~(c) + FIX-014 검증 R-14-7 의 (d) "임시 경로는 스크래치패드 리터럴 절대 경로" — 사용자 2026-10-11 FIX-033 위임 승인 때 포함):
   - (a) **계약 값은 값으로 단언한다.** 집계·정렬(2차 키 포함)·상한·경계·격리 조건마다, 그 코드를 바꾸면(예: max→min, `>=`→`>`, 조건 제거) 실패할 테스트가 있어야 한다. 보고에 "어떤 변이를 어떤 테스트가 잡는가" 표를 넣는다. 저장소 파일을 고쳐 변이를 돌렸다면 원복 후 `git diff` 로 원복을 보인다.
   - (b) **계획에 없는 상수·정렬·상한·추가 방어 조건이 필요하면 구현하기 전에 멈추고 보고한다**(값 후보와 이유). 메인 세션이 사용자에게 묻고 01-plan/03-log 에 기록한 뒤 진행. 사소해 보여도 같다.
   - (c) **증거 파일에는 명령 출력 전체를 Write 로 남긴다**(요약·발췌는 그 아래 따로). 길면 파일을 나눈다.
2. `.claude/skills/devlog/SKILL.md`: verifier 커밋 전 리뷰 위임 문구에 "단위마다 핵심 계약 변이 시험 최소 1개(저장소 밖 사본 또는 런타임 치환, 저장소 무수정)" 를 고정. 구현 위임 문구에 위 (a)~(c) 를 넣으라는 한 줄.

4. 판정(실제 명령 — verifier R-33-3 로 정정; 원안의 `구현하기 전에 멈추고`·`.claude/agents/*.md` 는 글자 그대로 돌리면 architect.md·verification.md 에서 0건이라 판정이 되지 않았다): `grep -c "값으로 단언\|구현하기 전에 멈추\|출력 전체\|리터럴 절대 경로" .claude/agents/backend-agent.md .claude/agents/eval-agent.md .claude/agents/frontend-agent.md .claude/skills/devlog/SKILL.md` 가 네 파일 모두 1 이상 + `grep -n "^## 변이 시험 방법" docs/wiki/verification.md` 1건(새 절 존재 — "리터럴 절대 경로" 는 61행 기존 문구에도 있어 새 절의 증명이 못 된다), `bash .claude/scripts/test-guards.sh` 의 에이전트 frontmatter 파싱 시험이 계속 ok(정의 파일을 고치므로).
