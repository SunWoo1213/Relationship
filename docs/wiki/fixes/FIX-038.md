# FIX-038 · 로그인한 화면에서 아이디를 보이지 않는다

발견: 2026-11-17 · 사용자 요청(평가 전날) | Refs: FIX-038 P9b-auth CR-007 D18 원칙5

## 증상

로그인한 뒤 사이드바 아래 계정 줄이 `<닉네임> · <아이디> · 로그아웃` 으로 보인다(`web/src/components/AppShell.tsx:49-67`, `data-testid="sidebar-username"`).
사용자 원문(2026-11-17): "로그인을 하고 들어가 있는 페이지에서 아이디는 보이지 않았으면 좋겠어".

## 원인

버그가 아니라 계획 결정이다. `packages/P9b-auth/01-plan.md` 결정 AF 가 (i) "<닉네임> · <아이디> · 로그아웃" 을 골랐다(이유: 기존 단언 5곳 유지, 시연 중 어느 계정인지 보임). 같은 표에 (ii) "<닉네임> · 로그아웃"(아이디 숨김)이 후보로 있었고, 사용자가 이번에 (ii) 를 골랐다.

## 수정안 (파일 · 방식 · 회귀 테스트)

- `web/src/components/AppShell.tsx`: 계정 줄에서 아이디 `span`(`sidebar-username`)과 그 앞 가운뎃점 하나를 뺀다. 결과 = `<닉네임> · 로그아웃`. 닉네임 `span`·로그아웃 버튼·실패 안내는 그대로.
- 로그인한 화면 어디에도 아이디 글자가 나오지 않게 한다. `web/src` 에서 로그인 뒤 화면이 `state.username` 을 그리는 곳은 이 한 곳이다(메인이 grep 으로 확인 — 구현자가 다시 확인한다). `auth.tsx` 의 상태 필드 `username` 과 `/auth/*` 응답 계약은 **바꾸지 않는다**(백엔드 무변경).
- 가입·로그인 화면의 아이디 입력 칸은 그대로다(로그인 전 화면).
- 테스트: `web/src/__tests__/auth.test.tsx` 의 `sidebar-username` 단언 7곳(105·154·458·472·560·582 등)과 `web/e2e/auth.spec.ts:32` 를 고친다 — 아이디로 계정을 구분하던 단언은 닉네임(`sidebar-nickname`) 단언으로 바꾸거나, 이미 닉네임 단언이 같이 있으면 아이디 단언을 "없다" 단언으로 바꾼다.
- 회귀 테스트(새로): 로그인한 화면에 ① `sidebar-username` 이 없다(`queryByTestId` → null) ② 닉네임과 아이디가 다른 계정에서 계정 줄 글자에 아이디 문자열이 들어 있지 않다 ③ 닉네임·로그아웃은 그대로 보인다.
- 변이: 아이디 `span` 을 되살리면 ①② 가 잡는다.
- 검증 명령: `npm --prefix web run test`(Vitest) · `npm --prefix web run build` · lint/typecheck 는 기존 스크립트 그대로.
- 문서: `packages/P9b-auth/01-plan.md` 결정 AF 줄에 "(2026-11-17 사용자 결정으로 (ii), FIX-038)" 한 마디를 덧붙인다(메인).
