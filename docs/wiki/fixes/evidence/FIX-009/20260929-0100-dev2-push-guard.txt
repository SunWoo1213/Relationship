# dev2 푸시 허용 검증 (2026-09-29)
# safety-guard 에 푸시 명령을 넣어 허용/거부 판정을 확인한다

## 1. 허용되어야 하는 것
### dev2 공유 푸시
$ git push origin dev:dev2
(위가 비어 있으면 통과 = 허용)
