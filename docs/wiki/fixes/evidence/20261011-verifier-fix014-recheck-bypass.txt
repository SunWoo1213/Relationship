## 실증 — 뚫린 5건을 이 세션의 Bash 툴(라이브 bash-write-guard 등록 상태)로 실행해 스크래치패드에 실제 파일을 만들었다
# 작업 디렉터리: <스크래치패드>/proof (프로젝트 밖). f.sh 내용: `echo x > app/n25.py` (Write 로 만듦). 모든 호출이 훅에 막히지 않고 실행됐다.
| 라벨 | 실행한 명령(cd <스크래치패드>/proof && mkdir -p app && …) | 결과 |
|---|---|---|
| P-N27 | `echo 'echo x > app/n27.py' \| xargs -I{} bash -c {}` | `-rw-r--r-- … 2 … app/n27.py` 생성 — 라이브 훅 통과 |
| P-N25 | `bash <<EOF` / `$(cat <스크래치패드>/proof/f.sh)` / `EOF` | `app/n25.py` 생성 — 라이브 훅 통과 |
| P-N30 | `printf "open('app/n30.py','w')" \| xargs -0 -I{} python3 -c {}` | `app/n30.py` 생성 — 라이브 훅 통과 |
| P-E1 | `cat <<EOF` / `$(echo x > app/e1.py)` / `EOF` | `app/e1.py` 생성 — 라이브 훅 통과 |
