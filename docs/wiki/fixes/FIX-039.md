# FIX-039 · 인물 카드·브리핑의 영문 키를 한글 이름으로 보여 준다

발견: 2026-11-18 · 사용자 요청(평가 당일 아침, 운영 화면 점검 중) | Refs: FIX-039 P9b-auth P8-frontend 원칙5 원칙7

## 증상

운영 화면(`https://relmemo.com/#/persons/3`)의 인물 카드에 서버 키가 영문 그대로 보인다.

- "알고 있는 것": `contact_note 아침 일찍 보고받는 걸 좋아함`, `likes 녹차`, `family …`, `dislikes 커피`, `life_event …`, `job 팀장`
- "반복 패턴": `pattern:conflict 6회 (…)`, `pattern:meeting 5회 (…)` …
- "타임라인": 사건 종류 배지가 `praise`·`conflict`·`meeting` …
- 브리핑 화면(`#/briefings`)의 패턴 줄은 `3회 (2026-11-09, 2026-11-16, 2026-11-16)` 처럼 **무엇이** 3회인지 없이 나온다(`pattern_sentences[].key` 는 있는데 그리지 않는다).

사용자 원문(2026-11-18): "영문 키를 한글로 바꿔줘".

## 원인

버그가 아니라 P8 의 계획 결정이다. `web/src/screens/PersonCardScreen.tsx:3` 주석 "서버 문자열(key · value · content · raw_utterance · title)은 고치지 않고 그대로 보여 준다 (원칙7)" 에 따라 `fact.key`(217행)·`event.type`(120행)을 그대로 그린다. 사용자가 이번에 **키와 종류의 표시 이름만** 한글로 바꾸기로 정했다.

## 수정안 (파일 · 방식 · 회귀 테스트)

프론트 표시만 바꾼다. 서버 응답·DB 값·MCP 도구 출력은 **바꾸지 않는다**(백엔드 무변경).

- 새 파일 `web/src/lib/labels.ts`: 표시 이름 표 3개와 함수.
  - 사실 키(`app/memory/types.py::FACT_KEYS` 9종, 순서 그대로):
    `job` 직업 · `workplace` 소속 · `family` 가족 · `hobby` 취미 · `likes` 좋아하는 것 · `dislikes` 싫어하는 것 · `health` 건강 · `life_event` 근황 · `contact_note` 연락·만남 메모
  - 사건 종류(`app/db/models.py::EVENT_TYPES` 7종):
    `conflict` 갈등 · `praise` 칭찬 · `meal` 식사 · `meeting` 만남 · `personal_share` 개인 이야기 · `favor` 도움 · `other` 기타
  - 패턴 키 `pattern:<type>` → `<사건 종류 한글>` (예: `pattern:conflict` → `갈등`). 접두사 `pattern:` 는 보이지 않는다.
  - **표에 없는 키·종류는 받은 문자열 그대로** 돌려준다(숨기거나 지어내지 않는다). `pattern:<모르는 type>` 도 원문 그대로.
- `web/src/screens/PersonCardScreen.tsx`: 사실 줄·패턴 줄의 키 자리와 타임라인 배지에 위 표시 이름을 쓴다. 3행 주석을 "키·사건 종류는 표시 이름으로 바꿔 보여 주고(FIX-039), value · content · raw_utterance · title 은 그대로" 로 고친다. **value·content·원문·일정 제목은 한 글자도 바꾸지 않는다.**
- `web/src/screens/BriefingScreen.tsx`: 패턴 줄을 `<표시 이름> <sentence>` 로 그린다(예: `만남 3회 (2026-11-09, …)`). `sentence` 자체는 그대로. `lines`·`suggestion` 은 건드리지 않는다.
- `web/src` 의 다른 곳에서 `fact.key`·`event.type`·`pattern:` 을 화면에 그리는 곳이 더 있으면 같은 함수를 쓴다(구현자가 grep 으로 확인해 보고한다).
- 테스트: 기존 `web/src/__tests__/card.test.tsx`·브리핑 테스트에서 영문 키를 화면 글자로 단언하던 곳을 한글로 고친다. 새 회귀 테스트: ① 사실 키 9종·사건 종류 7종이 각각 정해진 한글로 보인다(값으로 단언) ② 패턴 줄에 `pattern:` 글자가 없다 ③ 표에 없는 키·종류는 원문 그대로 보인다 ④ value·content 는 서버 문자열 그대로다 ⑤ 브리핑 패턴 줄이 `<한글> <sentence>` 다.
- 변이: 표의 한 항목을 다른 글자로 바꾸면 ① 이, 모르는 키를 빈 문자열로 돌려주게 하면 ③ 이 잡는다.
- 검증 명령: `npm --prefix web run test` · `npm --prefix web run build` · 기존 lint/typecheck 스크립트.
