## 증상

- FIX-018~025 여덟 건에 verifier 가 한 번도 들어가지 않았고, 각 FIX 문서의 `검증: 통과` 줄을 메인 세션이 썼다(L-002 미이행). 그 사이 FIX-020 이 `updated_at` 회귀를 만들었고 사후 검토가 잡았다(FIX-026).
- devlog `/devlog fix` 3단계가 "정합성 점검표 적용 → `검증: 통과`" 라고만 적어, 계획 작성자(메인 세션)가 검증 줄을 쓰게 되어 있다. 계획(`verify-plan.sh:86`)·완료 검토(`verify-impl.sh:101`)에는 "검증자/검토자 줄에 verifier 없으면 FAIL" 기계 검사가 있지만 **FIX 에는 없다.**
- 활성 패키지가 있는 동안 진행한 FIX 는 `stage-gate.sh` 의 FIX 분기를 타지 않는다(R-26-4).
- 메인 세션이 CI 설정·테스트 같은 작은 수정을 직접 했다(원칙: 메인 세션은 조율·승인·커밋만).
