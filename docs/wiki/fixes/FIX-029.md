# FIX-029 · `app.push` 를 먼저 import 하면 순환 import 로 실패한다

발견: 2026-10-10 · P7-push 04-review(verifier 변이 실험 중, HEAD `6428180`) · 05-remediation `F-c7c1e5` | Refs: FIX-029 F-c7c1e5 P7-push S3.6 R12

## 증상

- 새 인터프리터에서 `app.push` 계열 모듈을 **먼저** import 하면 실패한다. 증거 `packages/P7-push/evidence/20261010-2005-review-import-cycle.txt`:
  ```
  import app.push               ImportError: cannot import name 'notifier_from_env' from partially initialized module 'app.push.notifier' (most likely due to a circular import)
  import app.push.notifier / .sender / .payload / .subscriptions / .types   (같은 메시지)
  import app.briefing           (성공)
  import app.main               (성공)
  ```
- 메인 세션 재현(2026-10-10): `.venv/bin/python -c "import app.push"` → 같은 ImportError, `.venv/bin/python -c "import app.main"` → exit 0.
- 01-plan U1 판정 명령 `python -c "import app.push"` 가 HEAD 에서 실패한다(U1 시점에는 성공 — 그때는 `notifier.py` 가 없었다).
- 지금 영향 없음: 서버 진입점(`uvicorn app.main`)·테스트 1873건(conftest 가 `app.main`/`app.briefing` 을 먼저 올림)·U8 실발송은 전부 briefing → push 순서로 올라간다. 순서가 바뀌는 스크립트·단독 테스트 실행·향후 import 정리에서 깨진다.
