# FIX-024 · 순수 함수의 "항상 지켜야 할 성질" 을 속성 기반 테스트로 확인한다

## 증상

예시 기반 테스트만 있다 — 사람이 고른 입력 몇 개로 확인한다. FIX-021 에서 브리핑 검증기에 해시 불가 키가 들어오면 "예외를 던지지 않는다" 는 약속이 깨지는 것을 손으로 찾았다 — 이런 경계 입력을 도구가 자동으로 찾는 장치가 없다.

## 원인

테스트 도구가 pytest 만이었고, 순수 함수의 불변식(값 범위·단조성·원문 미포함·무예외)을 성질로 적어 둔 곳이 없었다.
