# D5 · 임베딩은 별칭 단위

상태: 유효 | 해결하는 검증: R9 | 원문: `docs/resolution-plan.md` §1 D5

**결정** `person_embeddings` 테이블 없음. `person_aliases.embedding`에 별칭마다 벡터. 후보 검색 = 별칭 top-K(K=10) → 인물별 max 유사도.

**이유** "김팀장" 벡터 하나로 "부장님"을 못 찾는다. 별칭이 쌓일수록 검색이 좋아진다는 기획서 4장 주장이 이 구조에서만 성립.

**코드에서 지켜야 할 것** 인물당 대표 벡터를 만들지 않는다. 새 별칭이 확정(`confirmed_at`)되면 즉시 임베딩한다.
