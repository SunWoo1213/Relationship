```
1. 후보 검색   별칭 임베딩 top-K(K=10) → 인물별 max 유사도 → s_emb
2. 규칙 필터   호칭 사전 호환 / 위계 일치 / 관계 태그 일치 → s_rule (D13: 관계 태그·위계 충돌은 감점·후보 유지, 사전 모순만 제외)

4. 분기        confidence = Σ w_i·s_i / Σ w_i (관측 신호만, w = 0.5/0.3/0.2 — D12; 세 신호 모두 있으면 0.5·s_llm + 0.3·s_emb + 0.2·s_rule, s_rule 미측정이면 0.625·s_llm + 0.375·s_emb)

              < T_new          → ask_user(kind="new_person")
```
