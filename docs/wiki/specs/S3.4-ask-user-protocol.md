# S3.4 · ask_user 프로토콜

원문: `docs/resolution-plan.md` §3.4 · 관련: D1 D2 · 적용: P2-tools, P5-loop, P8-frontend

```
턴 N   발화 → 루프 → ask_user → pending_questions 저장 → 응답에 question_id → 턴 종료
턴 N+1 칩 선택 → POST /answers/{question_id} → 저장된 context로 루프 재개 → 후속 툴
```

- 답 없이 다음 발화가 오면 대기 질문 유지, 새 발화 우선.
- 미답변 24시간 후 만료(`answered_at` null 유지, status=expired).
- 프론트 확인 칩 = 미답변 pending_questions.
- `context`에는 재개에 필요한 것만(발화, 후보 id, 확신도 분해). 비밀·전체 대화 이력 저장 금지.
