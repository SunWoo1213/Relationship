# S3.5 · 메모리 승격 + 패턴 감지

원문: `docs/resolution-plan.md` §3.5 · 관련: D14(D9 대체) R8 R11 원칙6 · 적용: P6-memory

- 3계층: 작업(인메모리 최근 N턴) / 에피소드(`events`, 원문 보존) / 시맨틱(`person_facts`).
- 승격 트리거: 같은 인물의 미승격 events ≥ 5건(설정값 `MEMORY_PROMOTE_MIN_EVENTS`, 기본 5 — 2026-09-28 사용자 결정, 기본값 불변).
- 승격 동작: LLM이 사실 후보 추출 → `person_facts` upsert → 각 사실을 `fact_sources`로 근거 이벤트에 연결.
- 패턴: 같은 type 이 설정된 기간(`PATTERN_WINDOW_DAYS`, 기본 365일) 내 설정된 횟수(`PATTERN_MIN_COUNT`, 기본 3회) 이상 → `pattern:{type}` 사실 (규칙, D14 — CR-002 로 D9 의 90일 대체). LLM은 문장화만.
- **원문은 어떤 경우에도 삭제하지 않는다.**
- 보충(CR-009 · D20, 2026-11-22): ① **사실 표시 단조 규칙** — 사실의 민감 여부는 `person_facts.sensitive_category` 하나로 정하고, 모든 쓰기(루프 upsert·직접 사실·승격 upsert, "값 같음" 분기 포함)는 `COALESCE(기존, 이번 쓰기의 범주)` 로만 바꾼다(올라가기만, `fact_sources` 링크는 끊지 않는다) ② **승격 입력 제외** — 승격 추출 LLM 에 민감 사건 원문·민감 사실을 넣지 않고 민감 사건은 미승격 사건 수(`MEMORY_PROMOTE_MIN_EVENTS`)에도 세지 않는다(동의 뒤 OpenAI 재전송 0 — 결과로 동의한 민감 사건은 요약 사실로 이어지지 않는다) ③ 패턴은 민감 사건을 세지 않는다(D14 보충). 위 "원문은 삭제하지 않는다" 는 **저장된 에피소드(`events`) 원문**에 대한 문장이다 — CR-009 의 거절·만료 지우기는 저장되지 않은 문장(대화 기록·대기 질문·trace)만 대상이라 이 문장과 부딪히지 않는다.
