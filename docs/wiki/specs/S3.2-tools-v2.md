# S3.2 · 툴 시그니처 v2

원문: `docs/resolution-plan.md` §3.2 · 관련: D1 D2 D6 R10 · 적용: P2-tools

| 툴 | 시그니처 | 비고 |
|----|----------|------|
| `search_person` | `(query: str, hints?: {hierarchy?, relation_tag?}) → Candidate[]` | 규칙 필터 힌트 |
| `create_person` | `(display_name, aliases: str[], relation_tag, hierarchy) → Person` | D1: answered new_person 질문 뒤에만 |
| `update_person` | `(person_id, facts?: {key,value}[], new_alias?: str, display_name?: str) → Person` | 승진: 별칭 누적 + 표시 이름 갱신(D6) |
| `add_event` | `(person_id, type, content, occurred_at, raw_utterance) → Event` | 런타임이 raw_utterance 자동 주입 |
| `add_schedule` | `(person_id, title, scheduled_at) → Schedule` | |
| `get_briefing` | `(person_id, schedule_id?) → Briefing` | `briefed_at` 기록 |
| `ask_user` | `(kind, question, options, context) → PendingQuestion` | D2 비동기. 독립 툴 유지 |

`Candidate = {person, similarity, aliases_matched, rule_flags}` — 3단계 LLM 판정 입력.
모든 툴 호출은 `agent_traces`에 input/output/tokens 기록(원칙9).
