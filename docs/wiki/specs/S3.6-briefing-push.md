# S3.6 · 브리핑 트리거와 푸시

원문: `docs/resolution-plan.md` §3.6 · 관련: R12 원칙7(경계) · 적용: P6-briefing, P7-push

- 주기 작업(컨테이너 내, 1분): `scheduled_at - now() ≤ 24h AND briefed_at IS NULL` → `get_briefing` → 웹푸시 → `briefed_at`.
- 수동 트리거 `POST /briefings/run` = 같은 함수. 데모 "시간 앞당기기"와 "발표자 수동 버튼" 겸용.
- 브리핑 내용: 기록된 사실·패턴·최근 사건. **제안은 사실에서 도출되는 한 줄 행동 제안으로 한정**, 감정·고민 대화 금지.
- 푸시 구독은 `push_subscriptions`. VAPID 키는 SSM/환경변수, 코드·저장소에 두지 않는다.
