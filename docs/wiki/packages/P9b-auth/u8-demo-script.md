# P9b-auth U8 · 시연 계정에 넣을 대화 (메인 세션 작성, 2026-11-16)

> 목적: 시연 (나) "이미 데이터가 들어가 있으면 어떻게 해 주는지" 를 보이기 위해, 배포본의 **시연 계정**에 제품 파이프라인 그대로(채팅) 데이터를 쌓는다. DB 에 직접 넣지 않는다(결정 Q).
> 이 목록은 제안이다 — 인물·내용은 사용자가 바꿔도 된다. 평가 데이터셋·라벨과 무관하다(원칙8).
> 확인 칩이 뜨면 **사용자가 직접 판단해 누른다**. 아래 "기대" 는 흐름 설명이지 정답 강요가 아니다(원칙1 — 자동 병합을 유도하지 않는다).
> 한 줄씩 보내고 답을 본 뒤 다음 줄을 보낸다. 발화 하나는 2000자까지.

## 언제 넣나
- 배포 반영(13 문서 G-3~G-6)과 시연 계정 가입(G-7) 뒤, **11-17(화) 저녁**에 1~12번을 넣는다.
- 13번(일정)은 **시연 시각 기준 24시간 안**이어야 브리핑이 만들어진다. 11-17 저녁에 넣는다면 "내일(11-18) 시연이 끝난 뒤 시각" 으로 잡는다. 넣고 1~2분 뒤 브리핑 화면에 브리핑이 생긴다(한 일정에 브리핑은 한 번만 만들어진다).

## 발화 목록

| 1 | 오늘 김민수 팀장님이랑 회의하다가 일정 문제로 또 부딪혔어 | 인물 1(직장·위) + 사건 `conflict` | 새 인물 확인 칩 → "직장으로 기억할게요" |
| 2 | 지난주에도 김민수 팀장님이 내 보고서를 사람들 앞에서 지적해서 좀 그랬어 | 같은 인물 `conflict` 2회째 | 칩 없이 기록(이름이 같아 자동 연결되거나, 확인을 물으면 "맞아요") |

| 10 | 박준호 대리가 내 자료 정리를 도와줘서 일이 일찍 끝났어 | 인물 4(직장·동/아래) + `favor` | 새 인물 확인 칩 → "직장으로 기억할게요" |

## 넣은 뒤 볼 것 (리허설 — 13 문서 G-9)
1. 인물 화면: 4명 카드. 김민수 카드에 사실·타임라인·패턴, 원문 펼침.
2. 브리핑 화면: 13번 일정의 브리핑 1건.
3. 로그아웃 → 다시 로그인: 위 대화가 채팅 화면에 이어서 보인다(최근 50줄).
4. 로그아웃 → **새 계정 가입**: 인물 0명, 채팅 기록 없음. 여기서 "오늘 김민수 팀장님 만났어" 를 보내면 시연 계정의 김민수와 무관하게 **새 인물 확인 칩**이 뜬다(계정 간 기억이 섞이지 않음).
5. 다시 시연 계정으로 로그인: 1~3이 그대로.

## 알아 둘 것
- 11-15 배포본 점검 때 "오늘 30분 뒤에 … 회의가 있어" 는 일정으로 저장되지 않았고 "내일 오후 3시 … 회의 일정" 은 저장됐다. 일정 발화는 13번처럼 날짜·시각·"일정" 을 분명히 쓴다.
- 시연 직전에 OpenAI 사용량을 확인한다(G-10).
- 시연은 탭 하나, 로그아웃은 채팅 화면에서.
