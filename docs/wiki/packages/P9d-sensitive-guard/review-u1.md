### 4.3 dev → test 누출

README 7절은 "같은 작성자·같은 날·문장 모양이 닮았다" 까지 적었다. 실제는 그보다 강하다.

- **test 는 dev 를 줄 번호 1:1 로 옮겨 쓴 꼴이다.** 같은 줄 번호끼리의 평균 유사도 0.468, 같은 묶음 안 임의 쌍 0.219. 같은 번호 쌍 중 유사도 ≥ 0.6: 평범 37/100 · 식별번호 20/90 · 동의 범주 5/75 · 함정 4/30 · 우회 0/20. 유사도 상위 40쌍 중 35쌍이 같은 줄 번호다.
