## 내용 규칙
- **pronoun 8건**: "걔·그 사람·아까 걔·그분·그 분·얘·쟤" 같은 지시 표현이 mention 이 되고, **선행사가 앞 턴에 있어야** 한다(같은 턴 안의 선행사도 가능하지만 대부분 앞 턴). 선행사 인물이 2명 이상 등장해 대명사가 누구를 가리키는지 문맥으로 정해지는 건을 절반 이상 넣는다(사람이 정할 수 있어야 한다). 사람도 못 정하는 mention 만 `ambiguous: true`·`gold_person_id: null` — 8건 전체에서 최대 3개. 대명사 mention 의 `surface` 는 발화에 그대로 있는 글자("걔가" 가 아니라 "걔" 처럼 조사 제외).
- **normal 10건**: 함정 없는 기준선 — 등록된 인물이 안정적 호칭으로 등장, 새 인물 등장 없음. `trap` 없음. 이 10건 중 3~4건에 **일정 발화**를 섞는다(예: "담주 화요일에 민준이랑 저녁", 라벨 필드는 없음 — 결정 C, P10 에서 라벨). events 는 실제 사건이 있을 때만.
- **persons/seed_persons**: 등장 인물 전원 `persons[]`, `seed_persons` 는 대화 전 등록 인물(대개 전원). 관계 태그 5종·위계 3종을 U2(직장 편중) 와 달리 가족·친구·연인·지인 쪽으로 더 배분.
- **expected_ask_user.allowed**: normal 은 대부분 `["none"]`. pronoun 은 문맥으로 정해지면 `["none"]`, 선행사 후보가 둘이라 시스템이 물을 수도 있으면 `["identity","none"]`, ambiguous 포함 건은 `["identity","none"]`.
- **구어체 규칙(검사 13)**: 발화 8~60자, 턴 2~6, 조사 생략·축약·ㅋㅋ·이모지 허용, 시나리오당 오타 1개 이하. 문어체 완결 문장만으로 쓰지 않는다.
- **범위**: 고민 상담·감정 조언 요청 발화 금지, 인물 간 관계는 배경으로만. **개인정보**: 실존 인물·실제 회사명 금지, 가상 성명만. 연예인은 일반 명사.
