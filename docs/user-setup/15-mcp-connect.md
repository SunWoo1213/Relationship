# 15. AI 도구에서 내 기억 꺼내 쓰기 (MCP 연결)

> 근거: CR-008 · D19 · security §1. 서버에 MCP 가 반영된 뒤에만 동작한다(반영 여부는 `docs/wiki/HANDOFF.md`).
> 이 문서의 모든 단계는 **사용자가 직접** 한다. 연결 토큰은 비밀이므로 에이전트(Claude Code 메인 세션 포함)에게 보여 주지 않는다.

## 1. 무엇이 열리는가

`https://relmemo.com/mcp` 에 **읽기 전용 도구 4개**가 열린다.

| 도구 | 하는 일 |
|---|---|
| `list_people` | 내 계정의 인물 목록 |
| `find_person` | 이름으로 인물 찾기 |
| `get_person_card` | 한 사람의 카드(사실·사건·일정·반복 패턴) |
| `list_briefings` | 만들어진 브리핑 목록 |

- 조회만 한다. 이 길로는 기록을 더하거나 고칠 수 없다.
- 내가 입력한 **대화 원문은 나가지 않는다.** 정리된 카드와 브리핑만 나간다.
- 토큰을 만든 **그 계정의 기억만** 보인다.

## 2. 연결 토큰 만들기

1. `https://relmemo.com` 에 로그인한다.
2. 왼쪽 사이드바의 **AI 연결**을 누른다.
3. **연결 토큰 만들기**를 누른다.
4. 토큰과 연결 명령이 화면에 나온다. **명령 복사**를 누른다.

토큰은 **이때 한 번만** 보인다. 화면을 떠나면 다시 볼 수 없다. 놓쳤으면 다시 만들면 된다.

## 3. Claude Code 에 붙이기

1. **내 컴퓨터의 터미널**을 열고, 복사한 명령을 붙여 넣어 실행한다. 모양은 아래와 같다.

   ```
   claude mcp add --transport http relmemo https://relmemo.com/mcp --header "Authorization: Bearer <토큰>"
   ```

2. 연결됐는지 본다.

   ```
   claude mcp list
   ```

   `relmemo` 가 연결됨으로 나오면 된다.

3. Claude Code 를 새로 열고 물어본다.

   - "relmemo 에서 내 인물 목록 보여줘"
   - "relmemo 에서 김민수 카드 보여줘"

**`--scope project` 를 붙이지 않는다.** 붙이면 저장소의 `.mcp.json` 에 토큰이 적혀 커밋될 수 있다.

연결이 실패하면 토큰이 잘못 붙은 경우가 대부분이다. 아래 4번대로 지우고, 토큰을 다시 만들어 명령을 다시 실행한다.

## 4. 폐기 · 다시 만들기 · 만료

- **폐기**: "AI 연결" 화면의 폐기 버튼. 누르는 즉시 그 토큰은 쓸 수 없다.
- **다시 만들기**: 새로 만들면 이전 토큰은 바로 무효가 된다. 계정마다 토큰은 하나다.
- **만료**: 만든 지 7일이 지나면 자동으로 무효가 된다.
- Claude Code 쪽 설정 지우기:

  ```
  claude mcp remove relmemo
  ```

시연이 끝나면 화면에서 폐기하고 위 명령으로 설정도 지운다.

## 5. 알고 써야 할 것

- 연결한 AI 도구가 조회한 내용은 **그 도구의 공급자(예: Anthropic)에게 전송된다.** 남에게 보이면 안 되는 내용이 든 계정은 연결하지 않는다.
- 토큰을 **채팅·문서·저장소·화면 공유에 붙여 넣지 않는다.** 에이전트에게도 주지 않는다. 터미널 명령 기록과 Claude Code 설정 파일(`~/.claude.json`)에는 남으므로, 다 쓴 뒤 폐기한다.
- **아직 안 되는 것**: Claude 앱(웹·데스크톱)과 ChatGPT 연결, 로그인 방식(OAuth) 연결, 기록을 더하는 도구. 지금은 Claude Code 에서 토큰으로 조회만 된다.

## 6. Codex CLI (시험하지 않음 — 확인 필요)

실제로 붙여 보지 않았다. 설정 모양만 적는다.

`~/.codex/config.toml`:

```toml
[mcp_servers.relmemo]
url = "https://relmemo.com/mcp"
bearer_token_env_var = "RELMEMO_MCP_TOKEN"
```

셸에서 `RELMEMO_MCP_TOKEN` 환경변수에 토큰을 넣고 실행한다.

## 7. 급히 꺼야 할 때 (서버 관리자)

MCP 길만 닫고 나머지 서비스는 그대로 두려면, 서버의 환경 파일에 `MCP_ENABLED=0` 한 줄을 넣고 아래를 실행한다.

```
docker compose -f docker-compose.prod.yml up -d
```

그 뒤 `/mcp` 는 404 가 되고, 채팅·인물 카드·브리핑은 평소대로 동작한다. 다시 켜려면 그 줄을 지우고 같은 명령을 실행한다.
